{\large\bfseries Supplementary evidence table}\\
{\itshape Hierarchical Taxonomic Abstraction for the Safe Handling of Novel
Objects in Autonomous Driving Perception} (v1, doi:10.5281/zenodo.21593472)

Accompanies the review exchange. Per-detection data: \texttt{cases.csv}
(54 rows). This sheet reports aggregates with explicit denominators.

\textbf{Evaluation set.} SegmentMeIfYouCan Road Anomaly, 40 images, 54
detections. Detector: YOLOv8s, class-agnostic NMS, confidence $\geq 0.20$.
CLIP: ViT-B/32. No training or fine-tuning.

\textbf{Population split (novelty is a proxy).} A detection is labelled
\emph{out-of-taxonomy} when the detector's COCO class has no node in our
taxonomy (e.g.\ giraffe, airplane). The detector already recognizes these
objects; this is a \emph{label-space gap}, not open-world novelty. It is
distinct from genuine, scale-dependent undecidability (the ``shampoo-bottle''
regime), which is not tested here. Out-of-taxonomy $n=20$; in-taxonomy $n=34$.

\textbf{Thresholds.} Leaf-softmax temperature $\tau=0.06$; commit-mass
$\theta=0.40$ (minimum subtree probability mass to descend one level); minimum
best-leaf cosine $\sigma=0.20$ (below this: immediate \textsc{unknown}). Safety
floors: Living Being, Vehicle, Static Object.

\textbf{Definitions.} \emph{Safe-handled} (out-of-taxonomy): the detection is
neither given a specific leaf nor dropped; it is abstracted to a category at or
below a safety floor, or flagged \textsc{unknown}. \emph{Useful category}
(in-taxonomy): outcome is not \textsc{unknown}, the reported node is below a
floor and on the correct root-to-leaf branch. The flat baseline's $0/20$ is
defined by the comparison rule (arg-max can only emit a leaf; the reject variant
drops), not yet by a fully equivalent empirical open-set baseline.

\textbf{Plausibility (stricter than safe-handled).} \emph{Safe-handled} only
requires that a detection is not given a confident leaf and not dropped. A
stricter check, \emph{plausibly abstracted / flagged}, additionally requires the
coarse category to be semantically correct: $15/20$ pass ($11$ flagged
\textsc{unknown}, $4$ abstracted to the correct floor), while $5$ abstract to an
implausible branch (airplane, kite and frisbee to \emph{Living Being}). Those are
out-of-ODD classes with no correct branch in the taxonomy, which is precisely the
gap a genuine open-world novelty test must target. See the \texttt{plausible}
column in \texttt{cases.csv}.

\textbf{Selection rule (manifest).} SegmentMeIfYouCan Road Anomaly, validation
split, the first 40 samples in Hugging Face streaming order (deterministic, no
shuffle). The \texttt{image} column in \texttt{cases.csv} (0..39) is the stream
position; each row is one detection. Per-image content hashes can be provided on
request for exact identification.

\textbf{Revised results statement.} Across 40 images, YOLOv8s produced 54
detections; 20 were out-of-taxonomy (the predicted COCO class has no taxonomy
node). All 20 satisfied the predefined fallback rule (9 abstracted, 11
\textsc{unknown}): \emph{20/20 fallback-rule coverage for detected
label-space-gap proxies}. This is not novelty-detection accuracy and not
demonstrated driving safety. Both the population assignment and the reference
class derive from the YOLO prediction, so the test shows internal behaviour
relative to a proxy label, not independent semantic correctness.

\textbf{Scope and caveats.} (i) Novelty is a label-space proxy, not open-world
novelty. (ii) Population and reference class both derive from the YOLO
prediction, not independent object-level ground truth. (iii) No box-level ground
truth: object-level false negatives and missed objects are outside the
evaluation; the KPI scores only detected objects. (iv) Sensor degradation and
broader domain shift are not evaluated. (v) The taxonomy provides bounded
semantic \emph{evidence}; authorization of any manoeuvre is a separate
(execution-governance) decision.
